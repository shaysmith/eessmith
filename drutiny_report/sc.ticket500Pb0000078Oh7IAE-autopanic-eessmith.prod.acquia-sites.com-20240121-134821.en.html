Automated Cron module should not be installed

  1. Normal
  2. Failure

The automated cron module will hijack page requests in order to run cron. This has a performance impact for end users who are unlucky being burdened with the task without consent and unknowingly.

Automated Cron core module is enabled. This could cause unexplicable slowness in some page requests.

Disable the automated_cron module and ensure cron is run via a system cron process such as crontab and using a non-web process such as drush. See Using scheduled jobs to support your application for more information.

Additionally, tools like XHProf or New Relic can provide insight into whether cron tasks are being executed within web requests, as well as their impact.

Unsupported modules

  1. Normal
  2. Failure

Community modules may at somepoint become unsupported. This happens for a number of reasons:

  • Maintainers make a release branch "end of life" to focus maintenance on more modern release branches.
  • Maintainers abandon the project and no longer maintain it.
  • Another module with similar functionality gains more usage and support and makes this module redundant.

For each unsupported module, there are three options to consider:

  • Remove the module. If the functions are not required or can be provided by another module, then you can remove the module.
  • Upgrade to latest supported version. If the project has a newer supported version that is compatible with your Drupal build, then you can upgrade the module to its latest version.
  • Become the project maintainer. If the project is abandoned but critical to your business, you may choose to become the project maintainer allow you to continue to get Drupal security coverage and community contributions.

Drush PHP compatibility

  1. Normal
  2. Failure

For the Drush commandline tool to work correctly, it should be running on a version of PHP it is compatible with. Different versions of Drush have diffent requirements.

In general, Drush versions are compatible with all PHP versions 7.3 and above (except Drush 10 which is incompatible with PHP 8). For more information see https://www.drush.org/11.x/install/

Drush 10.6.2 is not compatible with PHP 8.1.24.

  • Switch to different Drush version compatible with your Drupal and PHP version.
  • Alternatively, consider changing the PHP version to match your Drupal and Drush requirements.
  • See https://www.drush.org/11.x/install/ for the full compatibility matrix.
